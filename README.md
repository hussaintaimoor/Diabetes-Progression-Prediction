# 🩺 Diabetes Disease Progression Prediction

A regression project predicting quantitative diabetes disease progression one year after baseline, based on 10 physiological features (age, BMI, blood pressure, etc.).

## Dataset
Built-in `scikit-learn` diabetes dataset (442 samples, 10 features).

## Tech Stack
`Python` · `scikit-learn` · `Ridge Regression`

## How to Run
```bash
pip install -r requirements.txt
python src/train.py
```

## Results
- **RMSE:** ~55.5
- **R² Score:** ~0.42
